# setChat

A Node.js browser automation project that uses Puppeteer to interact with WhatsApp Web and send reminder messages.

# Technologies

- JavaScript
- Node.js
- Puppeteer
- WhatsApp Web

# Requirements

- Node.js and npm
- Google Chrome or a compatible browser
- A WhatsApp account

# Installation

Clone this repository and open its folder in a terminal.

```bash
npm install
```

# Usage

Review `index.js` and configure the recipient, message, and sending behavior before running the script.

```bash
node index.js
```

The script opens WhatsApp Web in a browser. You may need to authenticate manually.
